## Notes

- No reference source roots should live under `/tmp`; `/tmp` is still acceptable
  for transient subprocess work directories, logs, caches, and benchmark output.
- Large C++ references were intentionally not rebuilt during this localization
  pass. Their source roots are durable and the table records the rebuild command.
- If an upstream cannot be reached in a future environment, keep the manifest row
  and mark `Status` as `MISSING` with the exact clone or build failure.
