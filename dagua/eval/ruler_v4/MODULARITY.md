# RULER V4 module boundaries

`scene.py` and `ingestion.py` own immutable validated inputs, `registry.py` dispatches the 45 independent contract implementations, `weights.py` carries explicit P5-supplied sub-term mass and provenance plus dof and PM-1 accounting, `composition.py` turns VALUE/NA facet rows into the exact monotone pre-map loss and applies the event-registry strict-margin rule, `headline.py` provides only the RENAME-compliant ordinal map, and `score.py` is the deterministic no-I/O orchestration seam that publishes separated TYPE-R context and TYPE-M measurements. Phase 3 can therefore compile each facet and composition operation behind the same `FacetResult` and `CompositionResult` shapes, propagate certified per-term intervals through `compose`, race candidates on `L_total`, and register the finalized scorer without changing ingestion, attribution, weight provenance, headline semantics, or the event-margin comparison API.
