## Cross-Algorithm Patterns
1. Shortest-path preprocessing dominates these files: every algorithm except `_graph_distances.py` is fundamentally “graph distances first, geometry second.”
2. Three reusable embedding motifs recur: dense spectral embedding (`classical_mds.py`), landmark embedding (`pivot_mds.py`), and iterative stress optimization (`kk.py`, `stress_majorization.py`, `stress_sgd.py`, `maxent_stress.py`).
3. Unreachable-pair handling is inconsistent across files: KK uses `1e6`, MDS/PivotMDS use `max_finite+1`, and maxent uses `avg_edge_cost*sqrt(N)`.
4. Seed behavior is mostly deterministic and localized: KK and classical MDS ignore seed entirely; pivot MDS consumes one CPU-torch random draw; stress majorization uses one NumPy `default_rng(...).normal`; stress-SGD uses the global legacy NumPy RNG; maxent uses multiple fresh CPU-torch generators in different branches.
5. Most iterative solvers use fixed iteration counts and not true convergence checks; KK is the exception because SciPy owns its stop criteria.
6. The same normalize-to-extent heuristic appears in classical MDS, pivot MDS, and maxent; KK uses a simpler center-and-unit-rescale helper instead.
7. Pivot MDS is a central dependency: maxent uses it for initialization in both branches, and stress-SGD’s large-graph path reuses the same landmark-distance idea without the SVD embedding step.
8. The op taxonomy is directionally right, but the real code shows that “stress” needs finer-grained ops: exact-pair stress, pivot stress, KK springs, dense SMACOF, pairwise SGD, and node-wise majorization are materially different kernels.
