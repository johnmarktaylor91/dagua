# R74m-O2: Stress Metric + Scale/Alignment/Normalization Audit

**Verdict: The "battery" stress metric that gates the 3Q rung and forces 574 rung-4
verdicts is NOT scale-invariant and NOT properly normalized. It measures raw
coordinate-scale mismatch, not layout quality. The stress signal in the equivalence
battery is, for a large fraction of rung-4 combos, a SCALE ARTIFACT. CONFIDENCE: HIGH
(proven empirically + by code + by traced combos).**

---

## 1. There are TWO different stress functions, and they disagree

### (a) Diagnostic stress -- SCALE-INVARIANT (correct)
`dagua/eval/distributional_fidelity.py:241-269` `stress_per_layout()`
- Computes closed-form optimal scale `alpha = sum(layout_d * graph_d) / sum(layout_d^2)`
  (line 263-266), then `sum((alpha*layout_d - graph_d)^2) / sum(graph_d^2)` (267-269).
- Because `alpha` absorbs any global scaling of the coordinates, this stress is
  EXACTLY invariant to the absolute scale of the layout. Unweighted.
- Feeds fields: `stress_D_mean`, `stress_R_mean`, `stress_margin`, `stress_p_tost`.
- Wired in `scripts/definitive_fidelity_analysis.py:1026-1030` (`compute_mode_a_stress`)
  and `:1060-1064` (mode B). Margin = `max(0.05*mean(stress_R), 1e-6)`.

### (b) Battery stress -- SCALE-SENSITIVE (the problem)
`dagua/eval/equivalence_metrics.py:384-421` `normalized_stress()`
- Computes `sum(w*(layout_d - graph_d)^2) / sum(w*graph_d^2)`, `w = 1/graph_d^2`
  (line 417-421). **NO optimal-scale term.** `layout_d` enters raw.
- Therefore scaling the layout by `c` changes the value: it is a quadratic in `c`,
  minimized only when the layout's absolute scale already matches graph-theoretic
  distances. A layout at the wrong absolute scale (same SHAPE) gets an inflated value.
- Feeds fields: `battery_stress_D_mean`, `battery_stress_R_mean`,
  `battery_stress_margin`, `battery_stress_p_tost`. Margin = `max(0.02*mean, 1e-6)`
  (`quality_stress_margin`, analysis:1376-1389).
- This is the metric inside the 3Q intersection-union battery
  (`quality_battery_record`, analysis:1312-1373); battery passing -> rung "3Q",
  failing -> rung "4" (`distributional_fidelity.py:362-411`, `assign_rung`).

### No Procrustes / scale / aspect alignment before EITHER stress
Stress is computed on RAW stored coordinates. The Procrustes machinery
(`pairwise_procrustes_matrix`, `anisotropic_procrustes`) is used ONLY for the
LAYOUT-distance rungs (1/2), never piped into stress. So a pure scale difference
between dagua and reference flows straight into battery stress.

## 4. How widespread (570 rung-4 combos with finite stress)

- **185 / 570 (32%)** show the pure scale-artifact signature: battery off by >2x
  while scale-invariant `|D-R|/R` < 20%. For these 185:
  - scale-INVARIANT `|D-R|/R`: median **0.072**, p90 0.178, max 0.199.
  - scale-SENSITIVE `|D-R|/R`: median **1.00**, p90 5.25, max **102x**.
- Direction: battery says dagua "better" (<0.98x) in 68.8% and "worse" in 25.4% --
  i.e. NOT a one-directional quality loss, it's bidirectional scale jitter, exactly
  what a scale-coupled (not quality) metric produces.
- Normalization smell: across ALL combos, `battery_stress_R_mean` has **median 8224**,
  p95 197673, max 9.84e9. A properly normalized stress is O(0.01-1) (the diagnostic
  confirms ~0.03). These values are unnormalized scale-coupled magnitudes.

## 5. Important caveats (rigor, not laundering)

- The hypothesis (FP-floor must be quality-indistinguishable) is supported for the
  STRESS axis: when measured scale-invariantly, the median rung-4 invariant gap is
  ~7%, not the ~10-20x the battery reports. BUT a 7% scale-invariant gap is still real
  and would NOT pass the strict 5% diagnostic TOST (0/574 rung-4 pass `stress_p_tost`);
  ~60% are within 10%, only ~8% within 5%. So fixing the metric does NOT make these
  "bit-exact" -- it reclassifies a SCALE artifact, leaving a smaller, real residual.
- The battery is an IUT (stress AND cross AND np). Even with a scale-invariant battery
  stress, only **16** of the 185 artifact combos would flip to 3Q directly (cross+np
  already pass). 147 are also blocked by `cross_p_tost`, 80 by `np_p_tost`. So the
  scale-stress fix unblocks the STRESS axis but most combos have an independent
  crossing/NP difference that must be assessed separately (likely partly its own
  artifact -- crossing counts and k-NN overlap are also not scale-aligned; out of
  this sub-audit's scope but worth flagging).
- 134 rung-4 combos have GENUINE large invariant-stress divergence (inv ratio outside
  0.5-2x, mean dominated by a few combos with inv ratio in the thousands). Those are
  REAL, not artifacts -- do not launder them.

## 6. The fix (scale-invariant battery stress)

Replace the battery's `normalized_stress` (eq_metrics.py:417-421) with the
closed-form optimal-scale formulation already in `stress_per_layout`
(distributional_fidelity.py:263-269): fit `alpha` per layout before computing
residual. Concretely, in `normalized_stress`:

```python
alpha = sum(w * d_layout * d_graph) / sum(w * d_layout^2)   # weighted optimal scale
numerator = sum(w * (alpha*d_layout - d_graph)^2)
return numerator / max(sum(w*d_graph^2), EPSILON)
```

(keep the `w = 1/d_graph^2` weighting to preserve the metric's intent, just add the
weighted `alpha`). This makes the battery stress a TRUE quality metric: invariant to
the OGDF/graphviz-vs-dagua absolute-scale mismatch, comparing only layout SHAPE
fidelity to graph distances. Then re-derive `battery_stress_margin` from the new
(O(1)) reference values. EXPECT: the 20x/14x inflations collapse to the ~5-7%
invariant level seen in `stress_per_layout`; the 3Q battery stress axis stops being a
scale gate. (Note: `stress_quality_equivalence` and `equivalence_verdict`'s
`stress_rel_delta < 0.02`, eq_metrics.py:595, use the same unscaled stress and inherit
the same artifact -- fix in one place.)

Do NOT relax the margin to paper over it -- that would be laundering. The fix is
making the metric scale-invariant, which is the correct definition of normalized
stress; the residual real gap (cross/np and the smaller invariant-stress gap) stays
visible.

**CONFIDENCE: HIGH** that the battery stress signal is a scale/normalization artifact
for ~185 (32%) of rung-4 combos; HIGH that the fix is the optimal-scale formulation;
MEDIUM that it materially changes final rungs (only 16 flip on stress alone -- the
cross/np axes are the next dominoes and need their own scale-alignment audit).
